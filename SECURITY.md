# Security

## Reporting a vulnerability or a leaked secret

Please do not open a public issue.

- **GDG members**: message the tech lead directly on Slack.
- **Anyone else**: use **Report a vulnerability** in the repository's *Security* tab when it is available, or contact us through the links on https://github.com/GDG-EPITA.

Describe what you found and how to reproduce it. We will answer as soon as we can; we are student volunteers.

## If you leaked a secret yourself

Revoke or regenerate it first, then tell the tech lead. Removing it from the Git history is not enough: it may already have been copied.
