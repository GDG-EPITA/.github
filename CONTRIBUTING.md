# Contributing to GDG on Campus EPITA

These rules apply to every repository of the organisation unless the repository has its own `CONTRIBUTING.md` or `CLAUDE.md`.

## The workflow

1. **Start from a ClickUp task.** Assign yourself, set it to *in progress*, comment `[DÉBUT]`.
2. **One task = one branch = one pull request.** Name the branch `<firstname>/<zone>-<topic>`.
3. **Commit in English** with the task id: `site: add events page (CU-869abc123)`.
4. **Open a pull request** with the template filled in. Only tick what you actually checked.
5. **Get one review.** Nobody merges their own pull request without an approval.
6. **Squash merge**, then close the ClickUp task with a `[BILAN]` comment.

## Never

- Push directly to `main`, or `git push --force` on someone else's branch.
- Commit a key, a password, a token or personal data. If one leaks, revoke it first, then tell the tech lead.
- List an AI (Claude, Copilot, Codex…) as author or co-author of a commit or pull request. You are the author of what you ship.

## Members

The full rules, the ClickUp conventions and the project template live in `GDG-EPITA/gdg-clickup` (members only).
