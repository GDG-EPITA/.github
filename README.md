# .github

Organisation-wide files for GDG on Campus EPITA.

- `profile/README.md` is the page shown on https://github.com/GDG-EPITA.
- `CONTRIBUTING.md`, `SECURITY.md`, `pull_request_template.md` and `.github/ISSUE_TEMPLATE/` apply to every repository of the organisation that does not have its own.

Change these files through a pull request, like any other project.
